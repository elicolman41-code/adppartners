RUN & Done

Recurring payroll on autopilot. Set it once, it runs itself.

What it is

If your payroll is the same every period, RUN & Done processes it for you automatically. No logging in, no clicking submit. Your people get paid, taxes get filed, and you only touch it when something actually changes.

When something changes

  • Skip one period. Turn it off for that payroll and it picks back up automatically the next one.
  • Raise, bonus, new hire, someone leaves. Make the change and RUN & Done uses the new numbers going forward.
  • You stay in control. You can review any payroll before it processes, or step in and run it manually any time.
One thing to know. If you use a general ledger connection, that has to be set up before RUN & Done can process. We handle it during onboarding.

State tax IDs

If you need a state withholding or unemployment number, you apply for it. If that's a headache, tell me and I'll send you the exact steps, or walk you through it on the phone.
