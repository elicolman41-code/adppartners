# Which Paychex report gives which balance
From ADP's Balances for Competitive Takeaways.

| ADP balance | Date range | Paychex report |
|---|---|---|
| YTD | 1/1 – today | Employee Earnings Report, unmasked |
| CQTD | start of quarter – today | Employee Earnings Report, unmasked |
| EE Info | all current year | Employee Earnings Report, unmasked. **Socials are in the EE/DD Profiles, not the report.** |
| DE9 equivalent | previous quarter | Quarter Reconciliation Return |
| DE9C equivalent | previous quarter | Wage Detail Report |
| 941 | previous quarter | 941 |
| FLT | payroll by payroll, current quarter | Cash Requirements · Payroll Journal · Department Summary |
| Direct Deposit | — | Direct Deposit Details Report, unmasked |

DE9/DE9C are the California names. Elsewhere it is the state's own quarterly reconciliation and wage detail. New York is the NYS-45.
